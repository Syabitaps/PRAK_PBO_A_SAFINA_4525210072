## Tujuan Praktikum

Praktikum ini bertujuan untuk memahami penggunaan Git sebagai sistem pengelola versi serta GitHub sebagai platform untuk menyimpan dan mengelola repositori secara daring.

## Tahapan Praktikum

1. Menginstal Git pada komputer.
2. Mengatur identitas pengguna Git menggunakan nama dan alamat email.
3. Mengatur nama branch utama menjadi `main`.
4. Membuat SSH key dan menghubungkannya dengan akun GitHub.
5. Memeriksa koneksi SSH ke GitHub menggunakan perintah `ssh -T git@github.com`.
6. Membuat repositori lokal dan menghubungkannya dengan repositori GitHub.
7. Menambahkan berkas ke staging area menggunakan `git add`.
8. Menyimpan perubahan melalui `git commit`.
9. Mengirim perubahan ke repositori GitHub menggunakan `git push`.

## Kesimpulan

Melalui praktikum ini, saya mempelajari dasar penggunaan Git dan GitHub untuk mengelola perubahan berkas serta menyimpan proyek secara daring. Saya juga memahami proses konfigurasi Git, penggunaan SSH untuk autentikasi, dan tahapan mengirimkan perubahan dari repositori lokal ke GitHub.
